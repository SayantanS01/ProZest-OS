# ProZest OS v0.0.7-rc1

**2026-11-24 · x86-64 UEFI release candidate**

Booting the ISO displays the ProZest framebuffer console, reports initialization results and stops at **KERNEL READY - M09**. The bootstrap processor is running on kernel-owned descriptor tables. Hardware interrupts remain disabled.

All 32 CPU exception gates have fatal handlers. Diagnostics use QEMU debugcon at port 0xE9 and include the saved instruction and stack pointers. For exceptions with a hardware error code the reporter preserves that word. For a page fault it also reports the faulting virtual address. Genuine invalid opcode and page fault delivery were tested in separate images using the release handler. The normal boot image contains neither trigger.

The normal configuration reserves emergency stacks for double fault, NMI and machine check. Their real delivery has not been demonstrated. IST4 and the stack-watermark tests belong to a separate experimental image. Runtime validation covers QEMU/KVM and selected TCG boots. Physical hardware, SMP, nested-stack recovery and guard pages remain unverified. Memory allocation, scheduling, userspace and filesystem support are future work.

Build with scripts/build-rc1.sh. ISO dist/ProZestOS-v0.0.7-rc1-x86_64.iso, 3,723,264 bytes. SHA-256 0921e7aa98c8ffbd49cb0332eddc067257a6e00043614ada77be4df69e1dd0d3. The release remains untagged and unpublished.
