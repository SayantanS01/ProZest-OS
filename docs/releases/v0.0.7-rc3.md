# ProZest OS v0.0.7-rc3

Locally validated UEFI x86-64 release candidate. Adds a PMM-backed virtual
memory manager and an active kernel-owned PML4 sharing inherited mappings.
Normal boots passed four configurations; three deliberate page-fault scenarios
passed KVM and TCG. See `docs/development/m11-vmm-integration.md`.

ISO: `dist/ProZestOS-v0.0.7-rc3-x86_64.iso`

SHA-256: `cc1d9dd3a6c51a2b21aa519e6c53106ebf10f7616124b2c180a3c918b3fb7d84`

Build: `bash scripts/build-rc3.sh` (default output `build/rc3/test.iso`).
Not a stable release; physical hardware, SMP and userspace remain unverified.
