# ProZest OS v0.0.7-rc4

Validated x86-64 UEFI release candidate for Q35/OVMF. Adds interrupt entry,
PIC/PIT, ACPI MADT discovery, IOAPIC routing and calibrated local APIC timer
bring-up. Four runtime boots and prior host regressions passed. Interrupt
sources are masked at the final IF=0 halt; no scheduler or persistent clock yet.
