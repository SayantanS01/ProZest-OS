# ProZest OS v0.0.7-rc2

Local release candidate: M09 CPU infrastructure plus M10 physical memory management. Bootable x86-64 UEFI ISO. Normal boot initializes the PMM and verifies single/contiguous allocation and release, then halts with interrupts disabled. No userspace, scheduler, VMM, or physical-hardware certification yet.
